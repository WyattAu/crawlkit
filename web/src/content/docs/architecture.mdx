## Crate Structure

```
crawlkit-core/    Core library: types, analyzers, storage, export, HTTP client
crawlkit/         CLI binary: clap-based argument parsing, progress display
crawlkit-api/     REST API: axum-based server with API key auth and rate limiting
```

## Data Flow

```
URL Queue -> DNS Prefetch -> Fetcher -> Parser -> Analyzers -> Storage -> Export
    ^                              |
    +---- Link Discovery ---------+
```

## Key Components

### Rate Limiter
Token-bucket per domain with global bucket. Concurrency semaphore. Async-safe (no MutexGuard across await).

### Circuit Breaker
Three-state machine: Closed -> Open -> HalfOpen. Configurable failure/success thresholds and cooldown.

### Backpressure
Bounded pipeline with configurable capacity. Prevents memory exhaustion under high concurrency.

### Analyzer Registry
28 analyzers dispatched in parallel. Each implements the `Analyzer` trait with `analyze(ctx, config) -> Vec<Finding>`.

## Wired Modules

The following modules are now integrated into the crawl pipeline:

### Observability
Atomic metrics collection for pages crawled, bytes fetched, fetch/analysis times, and throughput. Exported via `--metrics-json`.

### Resource Monitor
Enforces memory, CPU, disk, and page count limits. Replaces ad-hoc RSS checking.

### Circuit Breaker
Per-domain fault isolation. Opens circuit after consecutive failures, preventing cascade failures.

### Backpressure
Bounded pipeline with semaphore-based concurrency control. Prevents memory explosion under high concurrency.

### Determinism
Seed-based reproducible crawls via `--seed` flag. Same seed + same config = same output.

### Feature Flags
Runtime feature toggles via TOML configuration. CLI flags override config.

### JS Render Decision
SPA detection engine that identifies React, Vue, Angular, Next.js, Nuxt, SvelteKit pages.

### Playwright Integration
JavaScript rendering for SPA pages when `--javascript` is enabled.

### Alert Manager
Monitors crawl metrics and triggers alerts when thresholds are exceeded.

### Encryption at Rest
AES-256-GCM encryption for stored data when `--encrypt` is enabled.

## Thread Safety

- `RateLimiter`: `DashMap` for domain buckets, `parking_lot::Mutex` for global (dropped before await)
- `UrlQueue`: `DashSet` for dedup, `parking_lot::Mutex` for heap
- `Storage`: `rusqlite::Connection` (single-writer, WAL mode)
- `Metrics`: `AtomicU64` counters
- `AuditTrail`: `parking_lot::RwLock<Vec<AuditEvent>>`
