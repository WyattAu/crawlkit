# crawlkit Web Dashboard

React-based web dashboard for crawlkit.

## Features

- Real-time crawl monitoring
- User management
- Tenant management
- Role-based access control
- Dark mode support
- Responsive design

## Installation

```bash
cd dashboard
npm install
npm run dev
```

## Architecture

- **Framework**: React 18 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **UI Components**: Radix UI
- **Charts**: Recharts

## Security

- JWT authentication
- Role-based access control
- XSS prevention
- CSRF protection
