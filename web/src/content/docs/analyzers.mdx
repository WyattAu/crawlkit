## Analyzer Interface

Each analyzer implements the `Analyzer` trait:

```rust
pub trait Analyzer: Send + Sync {
    fn name(&self) -> &str;
    fn analyze(&self, ctx: &AnalysisContext, config: &CrawlConfig) -> Vec<Finding>;
}
```

## Finding Severity

- **Error:** Critical issues that block indexing or accessibility
- **Warning:** Issues that reduce SEO effectiveness
- **Info:** Observations and recommendations
