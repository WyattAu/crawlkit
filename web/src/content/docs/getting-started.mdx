## Prerequisites

- Rust 1.75+ (latest stable recommended)
- Git

## Build from Source

```bash
git clone https://github.com/WyattAu/crawlkit.git
cd crawlkit
cargo build --release
```

Binary output: `target/release/crawlkit`

## First Crawl

```bash
# Basic crawl
crawlkit crawl https://example.com --max-pages 50

# Custom settings
crawlkit crawl https://example.com \
  --max-pages 500 \
  --delay 200 \
  --concurrency 8 \
  --output crawl-data

# Generate HTML report
crawlkit report crawl-data/ --format html --output report.html
```

## REST API Mode

```bash
crawlkit-api --port 8080
```

Default API key: `ck_dev_default_key_for_testing` (development only).

> **Security warning:** The default API key is for local development only. Do not use it in production. Generate a unique key via `POST /api/v1/keys` and store it securely.

## Programmatic Usage

```rust
use crawlkit_core::{CrawlConfig, HttpClient, HtmlParser};
use crawlkit_core::analyzers::{AnalyzerRegistry, AnalysisContext};

let config = CrawlConfig::default();
let client = HttpClient::from_crawl_config(&config)?;
let registry = AnalyzerRegistry::new(&config);

// Fetch and analyze
let url = url::Url::parse("https://example.com")?;
let result = client.fetch(&url).await?;
let parsed = HtmlParser::parse(&result.body, &url)?;
let ctx = AnalysisContext {
    page: &parsed,
    status_code: Some(result.status_code),
    headers: &result.headers,
    response_time: Some(result.response_time),
    redirect_chain: &[],
    robots_txt: None,
};
let findings = registry.analyze(&ctx, &config);
```
